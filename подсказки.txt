--------------------------- Атрибуты: ------------------------
a: anchor - якорь
href: hyper reference -- гиперссылка
(Пример)
<a href="contacts.html">Контакты</a>
а ещё в href можно поставить заглушку "#" и это не будет ссылкой, но она 
останется в коде
<a #href="mailto:utmn@mail.ru">utmn@mail.ru</a>
<a #href="tel:+7 (111) 111 11 11">
Если не добавить mailto:, комп/телефон откроет почту чтобы написать на неё
!(но если нет mailto у меня почемуто переносит на страницу с надписью "файл найден")
Если не добавить tel:, то при переходе откроются "контакты" на телефоне чтобы позвонить по номеру

img: image - картинка
(Пример)
src: source - источник
alt: альтернативный текст
<img src="book.png" alt="Книга">

------------------- FlexBox Froggy игра -------------------
Свойства:
          justify-content: 
(выравнивает элементы горизонтально)
принимает следующие значения:
* flex-start: элементы выравниваются по левой стороне контейнера.
* flex-end: элементы выравниваются по правой стороне контейнера.
* center: элементы выравниваются по центру контейнера.
* space-between: элементы отображаются с одинаковыми отступами между ними.
* space-around: элементы отображаются с одинаковыми отступами вокруг них.

           align-items: 
(выравнивает элементы вертикально)
принимает следующие значения:
* flex-start: элементы выравниваются по верхнему краю контейнера.
* flex-end: элементы выравниваются по нижнему краю контейнера.
* center: элементы выравниваются вертикально по центру контейнера.
* baseline: элементы отображаются на базовой линии контейнера.
* stretch: элементы растягиваются, чтобы заполнить контейнер.

(Пример)
#pond {
display: flex;
justify-content: space-around;
align-items: end;
}
            flex-direction 
(задает направление, в котором будут расположены элементы в контейнере)
принимает следующие значения:
* row: элементы размещаются по направлению текста.
* row-reverse: элементы отображаются в обратном порядке к направлению текста.
* column: элементы располагаются сверху вниз.
* column-reverse: элементы располагаются снизу вверх.
